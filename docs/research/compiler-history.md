# Compiler research record — through IR-047

This index preserves the findings, rejected paths, and methodology of compiler research. Historical reports are **evidence, not present-tense runtime documentation**. Each archived report is byte-identical to the pinned [IR047 checkpoint](https://github.com/qwasdf-1/mcfunction-compiler/tree/9dcd9fc6386aad8ef21400cfcb7e2a4d051e739c); use the original-source links for historical relative references and line anchors. Some reported commands, scripts or Mixins deliberately do not exist in the maintained runtime. Do not revive a withdrawn optimization solely because a report discusses it. Reports already present in this directory remain available in their original location.

## Findings that constrain the integration

- IR010: revision-backed cross-command source value cache did not qualify for CPU benefit.
- IR023: mutable entity tag sets bypass normal mutation hooks; no general cached index.
- IR028: reduced dispatch overhead did not establish whole-event CPU improvement.
- IR036: backend cost model is uncalibrated, not an accepted selection policy.
- IR037–040: prepared metadata and narrow typed compound/score arithmetic paths.
- IR043–045: validated scoped native dispatch, terminal guards and native store paths.
- IR046/047: qualified incremental guard value and preflight reuse; not a general datapack speedup or mod compatibility guarantee.
- [Integration-001](../integration-001.md) records current integration decisions and outstanding gates.
